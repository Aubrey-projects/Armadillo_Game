# Overview
I made a simple game where you can move around a small play space as an armadillo using the WASD keys

My purpose was to learn how to procedurally animate, where the animation isn't fixed with keyframes,  instead it is generated and created as you move your character.

[Armadillo Game](https://youtu.be/KEvDox_qYc0)

# Development Environment

I used blender to create the mesh and rig of my armadillo character. I then imported it into Godot to create the play space and write the code to move the character around.

I wrote in GDScript.
